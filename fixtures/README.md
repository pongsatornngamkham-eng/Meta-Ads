# ไฟล์รายงานจำลองสำหรับทดสอบนำเข้า

**ทุกตัวเลขเป็นข้อมูลจำลอง ไม่ได้ดึงจาก Meta หรือเว็บไซต์จริง**
ชื่อแคมเปญและยอดสมัครทั้งสองแหล่งเป็นข้อมูลสมมติทั้งหมด
ไฟล์ใช้ schema ของ Dashboard รุ่น CSV-only ไม่ใช่ไฟล์ export ตรงจาก Ads Manager
ไม่ต้องใช้ access token หรือสิทธิ์บัญชีใด ๆ

## ไฟล์ที่แนะนำ

| ไฟล์ | เนื้อหา | ผลที่ควรได้ |
|---|---|---|
| `mock-meta-ads-october-2026.csv` | 4 แคมเปญ × 28 วัน, 1–28 ต.ค. 2026, 112 แถว | กราฟรายวัน ตาราง 4 แคมเปญ และรายงานไทย ไม่มีคำเตือนข้อมูลขาด |
| `mock-meta-ads-zero-metrics.csv` | 4 แคมเปญในวันเดียว ทุกยอดเป็นศูนย์ | ยอดรวมเป็น 0; CTR, CPC, CPM และ cost per registration เป็น — โดยไม่หารด้วยศูนย์ |
| `mock-meta-ads-partial.csv` | 8 แถว, 27–28 ต.ค. 2026; บางยอดสมัครว่างและวันสุดท้ายยังไม่สมบูรณ์ | แจ้งคำเตือน 2 ข้อ; ไม่แสดงยอดรวม registration และต้นทุนต่อการสมัครทั้งสองแหล่ง เพราะตัวหารมีข้อมูลไม่ครบ |

ทั้งสามไฟล์เป็น UTF-8 พร้อม BOM เพื่ออ่านชื่อไทยใน Excel บน Windows ได้
ใช้ `data_source=mock`, สกุลเงิน THB, เขตเวลา Asia/Bangkok,
attribution สมมติ `7-day click / 1-day view` และเวลารวบรวมสมมติ
`2026-10-29T09:00:00+07:00` อย่าเปลี่ยน `data_source` เป็น `csv` สำหรับไฟล์เหล่านี้
เพราะต้องคงป้ายข้อมูลจำลองไว้

## วิธีทดสอบ

1. ดาวน์โหลด CSV โดยใช้ปุ่ม Download raw file บน GitHub อย่าเซฟหน้า HTML เป็น CSV
2. เปิด Dashboard และกด **นำเข้า CSV** แล้วเลือกไฟล์แรก
3. เลือกทุกแคมเปญและช่วงวันที่ 1–28 ต.ค. 2026 แล้วกดใช้ตัวกรอง
4. เทียบค่ากับตารางด้านล่าง จากนั้นลองเปลี่ยนวัน/แคมเปญและส่งออกรายงาน
5. อัปโหลดไฟล์เดิมซ้ำ ควรแสดงว่าเคยนำเข้าแล้วและไม่นับยอดเพิ่ม
6. ลองไฟล์ศูนย์และไฟล์ข้อมูลไม่ครบแยกกัน แต่ละไฟล์เป็นคนละชุดข้อมูล
   จึงไม่บวกยอดรวมกับไฟล์ที่นำเข้าก่อนหน้า

การนำเข้าและบันทึกต้องมี PostgreSQL ที่เริ่มและ init แล้ว
ดู README-WINDOWS.md สำหรับวิธีเปิดระบบบน Windows

CTR/CPC/CPM คำนวณโดยระบบจากยอดรวม ไม่ต้องเพิ่มคอลัมน์สูตรในไฟล์

ตรวจว่าไม่มีวัน/แคมเปญซ้ำ ไม่มีผลลัพธ์ NaN/Infinity และข้อมูลจำลองติดป้ายครบ
