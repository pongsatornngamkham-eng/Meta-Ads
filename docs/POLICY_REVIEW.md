## ผลและขอบเขต

**การตรวจสาระนโยบาย Social Casino และกฎหมายไทยยังไม่ครบ**
ไม่มีข้อสรุปว่าเกมหรือโฆษณาถูกกฎหมายหรือได้รับอนุญาตจาก Meta
ความไม่มี cash-out ไม่ได้ยืนยันการยกเว้นจากข้อกำหนดทุกประเภท
ต้องตรวจ พ.ร.บ.การพนัน พ.ศ. 2478 และฉบับแก้ไข/กฎที่ใช้จริงกับกลไกเกม
กฎหมายโฆษณา/ผู้บริโภค และ PDPA ตามข้อมูลที่ใช้จริงจากแหล่งทางการ
ก่อนเปิดให้บริการเกมหรือโฆษณาควรให้ผู้เชี่ยวชาญไทยประเมินรูปแบบที่แท้จริง

งานที่สร้างในรุ่นนี้จำกัดเฉพาะหน้าจอสาธิตและการวิเคราะห์ CSV แบบทั่วไป
ไม่แสดงโฆษณา ไม่ตัดสินความถูกต้องของแคมเปญ ไม่เชื่อม API และไม่ลงโฆษณา
เงื่อนไขการเชื่อมบัญชีจริงยังคงถูกปิดไว้ รักษาข้อค้างนี้ให้เห็นชัดแทนการ
กล่าวว่าได้ตรวจผ่านแล้ว ไม่มี cloaking หรือเปลี่ยนหน้าให้ผู้ตรวจเห็นต่างกัน

## สถานะส่วนเสริมวันที่ 30 ต.ค. 2026

มี GET-only diagnostic reader และ worker ที่ปิดงานอัตโนมัติไว้ โดยทดสอบด้วย
mock responses/DB ไม่มีการส่ง credential จริงจากเครื่องพัฒนา
เพิ่มโหมด preview สำหรับทดสอบอ่านด้วยตนเองบนเครื่องผู้ใช้ และ production gates
การเพิ่มโค้ดเหล่านี้ไม่แก้ข้อค้างนโยบาย/กฎหมาย ไม่ยืนยันว่าแคมเปญได้รับอนุญาต
ผู้ใช้ทดสอบ Insights ผ่าน Graph API Explorer และ Telegram setup สำเร็จแล้ว
แต่ยังไม่ได้ยืนยัน Marketing API Full Access หรือการเปิด worker ตามเวลา
รายละเอียดปัจจุบันอยู่ใน [REPORTING.md](REPORTING.md)

## สิ่งที่ยังต้องยืนยันก่อนเปิด connector ต่อเนื่อง

1. อ่านนโยบาย Social Casino / Online Gambling and Games ฉบับปัจจุบันให้ครบ
   พร้อมวันที่และหลักฐานข้อกำหนดที่ใช้กับรูปแบบเกมนี้
2. ตรวจเงื่อนไขประเทศ อายุ การซื้อเครดิต และการขออนุญาตตามนโยบายที่พบจริง
3. ตรวจข้อกฎหมายไทยจากตัวบทที่มีผลใช้บังคับ ไม่อ้าง HTTP status เป็นผลตรวจ
4. ยืนยัน `ads_read` ที่ Meta อนุมัติ สิทธิ์ app/account และ support ของ API version
5. ออกแบบ connector เป็น GET-only จาก server พร้อม tests ของ pagination,
   error responses, rate limits, partial data และการไม่รั่วไหลของ token

ไม่มีการเปลี่ยนนโยบายเครือข่ายหรือ publish environment ในการพัฒนารอบนี้
